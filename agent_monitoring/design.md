# HSBC Agentic Monitoring Dashboard - Design Style Guide

## Design Philosophy

### Visual Language
- **Professional Excellence**: Drawing inspiration from HSBC's global banking leadership, the design embodies trust, stability, and technological sophistication
- **Geometric Precision**: Incorporating HSBC's iconic hexagon symbol as a foundational design element throughout the interface
- **Minimalist Sophistication**: Clean, uncluttered layouts that prioritize information hierarchy and user focus
- **Global Accessibility**: Design patterns that work across cultures and languages, reflecting HSBC's international presence

### Color Palette
- **Primary Red**: HSBC Red (#DB0011) - Used for primary actions, alerts, and key metrics
- **Secondary Red**: Deep Red (#A8000C) - For hover states and emphasis
- **Neutral Grays**: 
  - HSBC Gray (#6B7280) - Secondary text and borders
  - Light Gray (#F3F4F6) - Background sections and cards
  - Dark Gray (#374151) - Primary text
- **Accent Colors**: 
  - Success Green (#10B981) - Positive metrics and success states
  - Warning Amber (#F59E0B) - Caution and warning indicators
  - Error Red (#EF4444) - Critical alerts and errors
- **Background**: Clean white (#FFFFFF) with subtle hexagonal pattern overlays

### Typography
- **Primary Font**: "Univers" family (HSBC's corporate typeface) or fallback to system fonts
- **Display Typography**: Bold, large headings that command attention
- **Body Typography**: Clean, readable sans-serif for data and content
- **Monospace**: For technical data, code snippets, and metrics display

## Visual Effects & Styling

### Used Libraries
- **Anime.js**: For smooth micro-interactions and state transitions
- **ECharts.js**: For sophisticated data visualization with HSBC color schemes
- **p5.js**: For creative hexagonal background patterns and visual elements
- **Pixi.js**: For high-performance visual effects and animations
- **Splitting.js**: For advanced text animations and effects
- **Typed.js**: For dynamic text displays in hero sections
- **Splide**: For smooth carousel interactions

### Animation & Effects
- **Micro-interactions**: Subtle hover effects on interactive elements using 3D transforms
- **Loading States**: Hexagonal loading animations with HSBC red branding
- **Data Transitions**: Smooth chart animations and metric updates
- **Scroll Animations**: Gentle reveal effects for content sections
- **Background Patterns**: Subtle animated hexagonal grid patterns

### Header Effect
- **Hexagonal Hero Background**: Animated hexagon tessellation using p5.js
- **Gradient Overlays**: Subtle red-to-white gradients maintaining HSBC brand identity
- **Dynamic Metrics Display**: Real-time KPI updates with smooth number transitions
- **Geometric Shapes**: Hexagonal frames and containers for key content areas

### Component Styling
- **Cards**: Clean white backgrounds with subtle shadows and hexagonal accent elements
- **Buttons**: HSBC red primary buttons with geometric hover effects
- **Forms**: Minimalist input fields with hexagonal focus indicators
- **Navigation**: Clean horizontal navigation with hexagonal active state indicators
- **Data Tables**: Zebra-striped rows with red accent headers
- **Charts**: HSBC color palette with smooth animations and interactive tooltips

### Responsive Design
- **Mobile-First**: Optimized for high-resolution displays and mobile devices
- **Flexible Grid**: CSS Grid layouts that adapt to different screen sizes
- **Touch-Friendly**: Interactive elements sized appropriately for touch interactions
- **Performance**: Optimized animations and effects for smooth performance across devices

## Brand Integration
- **Hexagon Motifs**: Strategic use of hexagonal shapes in UI elements, backgrounds, and decorative features
- **Red Accents**: Consistent use of HSBC red for branding and key interactive elements
- **Professional Imagery**: High-quality, abstract imagery that reflects financial technology and innovation
- **Consistent Spacing**: 8px grid system for consistent spacing and alignment
- **Accessibility**: WCAG 2.1 AA compliance for inclusive design
